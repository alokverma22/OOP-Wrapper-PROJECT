## 📊 About Employee Management System
Employee Management System ek Object-Oriented Programming (OOP) based menu-driven Python project hai jise inheritance aur class structures ko seekhne ke liye banaya gaya hai.

It helps users manage data through:
🧩 OOP Principles (Inheritance & Polymorphism)
🐍 Python Class Structures (Person ➡️ Employee ➡️ Manager)
🔢 Dynamic object initialization
💻 Interactive console operations

## 💻 Terminal Usage Guide (How It Works)

| Choice | Operation | Inputs Required | Expected System Action |
| :---: | :--- | :--- | :--- |
| **1** | **👤 Create Person** | Name, Age | Initializes the base class object with standard identity attributes. |
| **2** | **💼 Create Employee** | Name, Age, ID, Salary | Inherits Person attributes and appends corporate employment records. |
| **3** | **👑 Create Manager** | Name, Age, ID, Salary, Dept | Inherits Employee metrics and registers unique administrative departments. |
| **4** | **🔍 Show Details** | Select Class Type | Triggers dynamic polymorphic overrides to print custom attributes. |
| **5** | **🛑 Exit System** | None | Securely closes the main loop and frees active runtime resources. |
